# Intrusion-Detection-IoMT
Built a Random Forest-based IDS model to detect DDoS attacks, malware, and unauthorized access using the CICIDS dataset. Performed data preprocessing and feature selection for improved detection accuracy. Integrated a Django server and chatbot for real-time alerts and monitoring.

🔹 Project Overview

Developed a machine learning-based Intrusion Detection System to detect DDoS attacks, malware, and unauthorized access in IoMT networks using the CICIDS dataset.

🔹 Objectives

	•	Detect malicious network activities
	•	Improve security monitoring for IoMT devices
	•	Provide real-time alerting support

🔹 Tools & Technologies

	•	Python
	•	Pandas, NumPy, Scikit-learn
	•	Django
	•	Dataset Used: CICIDS Dataset
	•   Source: Publicly available dataset for network intrusion detection

🔹 Key Features

	•	Random Forest classification model for intrusion detection
	•	Data preprocessing and feature selection
	•	Real-time alert notifications via chatbot integration

🔹 Key Insights

	•	Random Forest achieved effective detection accuracy across multiple attack types
	•	Feature selection improved model performance
	•	Real-time alerts enhanced threat response time

🔹 Outcome

Demonstrated the use of machine learning and data analysis techniques to improve cybersecurity monitoring in IoMT environments.
